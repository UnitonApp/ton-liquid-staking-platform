# Features

## Liquid staking for TON

Stake TON and receive a liquid representation of your staked position. You earn staking rewards without locking up tradable value.

## Stake and unstake

The service prepares both `stake` and `unstake` transaction payloads, which the user's wallet signs and submits to on-chain TON smart contracts.

## Live pool data

Query up-to-date staking pool statistics so the front-end can show users accurate information before they stake.

## Balance lookups

Fetch staked and available balances for any TON address.

## TON Connect wallet support

The platform integrates with wallets that support the TON Connect standard, giving users a familiar and secure signing experience.

## DEX backend service

The platform is designed as the backend layer for a decentralized exchange and staking interface on the TON blockchain.
